# PCAP Historis

Folder ini disediakan untuk ekspor packet capture historis dari Security Onion, khususnya jika PCAP yang berkaitan dengan alert Sguil tanggal 22 Oktober 2026 berhasil ditemukan.

Pada bukti yang tersedia saat penyusunan paket ini, alert Sguil historis dapat dilihat dan header paket untuk Alert ID `5.1183` dapat diperiksa, tetapi file PCAP historis belum terbukti tersedia. Jangan menyalin PCAP tambahan tanggal 26 November ke folder ini dan jangan menyebutnya sebagai capture tanggal 22 Oktober.
