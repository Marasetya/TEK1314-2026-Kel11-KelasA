# Panduan Blue Team Minggu 12

Dokumentasi DFIR Minggu 12 berada pada:

- `incident_response_report_minggu12.md`: laporan utama.
- `evidence/minggu12/README.md`: peta bukti Minggu 12.
- `evidence/minggu12/evidence_register.md`: daftar bukti aktual.
- `evidence/minggu12/chain_of_custody.md`: catatan penanganan dan pemindahan bukti.
- `evidence/minggu12/incident_timeline.md`: urutan kejadian berdasarkan timestamp.
- `evidence/minggu12/analysis/`: analisis forensik, dampak, dan tindakan respons.
- `evidence/minggu12/hashes/`: manifest SHA-256.

Paket ini membedakan event historis Sguil, log hasil akuisisi Ubuntu, dan PCAP tambahan tanggal 26 November. Jangan mengubah status bukti yang belum terverifikasi menjadi klaim keberhasilan.
